# Solution photography

Product photos for catalog solutions live here, one or more per solution.

To add photos for a solution, drop the file in this folder named after the
solution's `imageKey`. No code change is needed - files are picked up at build
time by filename.

    smart-knee.jpg                       one photo
    smart-knee-1.jpg, smart-knee-2.jpg   several, shown in filename order

The first image is used on cards and as the detail page's main image; any
others become a thumbnail gallery.

Solutions without photos fall back to a placeholder labelled "photo pending",
so the layout stays intact and the gap is visible rather than silent.

`imageKey` values in use: smart-knee, carbon-foot, socket, bionic-hand,
digital-scan, passive-limb, spinal-brace, carbon-afo, kafo, insole,
diabetic-care.

Note on rights: Mafaz is an authorised Ottobock distributor, so Ottobock
product imagery may be published here. Imagery from any other manufacturer
needs its own permission before it goes live.
